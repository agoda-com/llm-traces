# Security Policy

## Supported versions

Security fixes are released for the latest published version of the plugin only.
If you run an older version, upgrade to the latest release before reporting, unless the issue is the upgrade itself.

## Reporting a vulnerability

Do not open a public GitHub issue, pull request, or discussion for a security vulnerability.
Public reports let others exploit the problem before a fix is available.

Report it privately through GitHub private vulnerability reporting for this repository.
Open the [Security tab](https://github.com/agoda-com/llm-traces/security/advisories/new) and choose "Report a vulnerability".
Only the maintainers and you can see the report.

Please include:

- The plugin version and the Grafana version.
- A description of the issue and its impact.
- Steps or a minimal trace payload that reproduces it.

## What to expect

The maintainers review the report, confirm whether it is a vulnerability, and work with you on a fix and a coordinated disclosure.
Once a fix is released, the maintainers publish a security advisory describing the issue.
